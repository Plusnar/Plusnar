## Projeto em destaque

### 🎓 Assistente do Campus — RAG para informações acadêmicas

Assistente desenvolvido para facilitar o acesso a informações institucionais da Univille utilizando recuperação semântica e IA generativa.

**Principais contribuições:**

- Pipeline de ingestão e indexação de documentos;
- Busca semântica com embeddings e banco vetorial;
- Geração de respostas contextualizadas com LLMs;
- Cuidados para reduzir respostas sem base no conteúdo recuperado;
- Interface web responsiva com apresentação das fontes consultadas.

**Stack:** Python · LangChain · ChromaDB · Cohere/OpenAI · Vercel
